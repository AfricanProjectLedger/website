# African Project Ledger

Production-ready static website for GitHub / Cloudflare Pages.

## Core pages
- `index.html` — preserved homepage
- `signals.html` — terminal-style public Project Activation Ledger
- `coverage.html` — market, sector and corridor coverage
- `subscription.html` — membership and conversion architecture
- `editorial-policy.html` — independence, sourcing and corrections
- `recruitment.html` — executive search, mandates and candidate access
- `about.html` — institutional purpose and leadership

`subscribe.html` remains as a compatibility redirect to `subscription.html`.

## 15-minute publishing
- Public Signals: `content/signals.json`
- Recruitment mandates: `content/recruitment.json`
- Browser editor configuration: `.pages.yml`
- Publishing gateway: `publisher.html`
- Plain-language instructions: `PUBLISHING_GUIDE.txt`

Public JSON files must never contain member-only intelligence or candidate personal data.
